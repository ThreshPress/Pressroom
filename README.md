# PRESSROOM

Education publishing, in print. A ThreshPress studio.

Describe a lesson once. PRESSROOM develops an instructional blueprint, then presses it into presentations, articles, worksheets, organizers, quizzes, infographics, and more — without rewriting the teaching.

## What it does

- **Develop** — turn a prompt into a structured instructional blueprint (objectives, sequence, checks for understanding).
- **Press** — render that blueprint into classroom-ready formats.
- **Edit** — tune pages, copy, and visuals in a print-inspired workspace.
- **Export** — take materials out as HTML or QTI for LMS use.

Projects live in the browser (no account required).

## Stack

React, TanStack Start, Tailwind CSS v4.

## Local development

```bash
npm install
npm run dev
```

The app is built to run inside Grok App Builder. Some platform scripts (`scripts/with-app-env.mjs`, PWA branding) are part of that environment.
